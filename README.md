# femax-campanas

Campañas publicitarias de los clientes de Femax Media, en archivos markdown. Repositorio **privado**.

## Tenerlo en el Mac

```bash
git clone https://github.com/femaxmedia/femax-campanas.git ~/femax-campanas
cd ~/femax-campanas
claude
```

(Si Git pide iniciar sesión, usa tu cuenta de GitHub de femaxmedia.)

## Mantenerlo al día

```bash
cd ~/femax-campanas
git pull          # traer cambios
git add -A && git commit -m "Qué has cambiado" && git push   # subir cambios
```

## Cambiar de ordenador
Basta con repetir el `git clone` de arriba en el ordenador nuevo. Todo vive en GitHub.
